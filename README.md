# Word Counter

Live text statistics with word frequency, reading time and a character limit meter.

## Features

- Live counts for words, characters, characters without spaces, sentences and paragraphs
- Unique word count, longest word and average word length
- Estimated reading time at 200 words per minute shown as m:ss
- Top five words panel with proportional bars and stop words removed
- Character limit field with a meter that turns red once you pass the limit
- Clear, Copy text and Load sample buttons plus Ctrl/Cmd + Enter to copy
- Your text and limit are remembered in localStorage

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.
